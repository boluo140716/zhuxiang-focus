# 修行手册与品牌统一设计（2026-08-08）

- 状态：已获用户口头批准（2026-08-08：入口 A、形式 A、一并统一品牌名）
- 依据：brainstorming 结论（产品缺引导层：用户曾问"深度时段是来干嘛的"）

## 1. 背景与目标

产品功能已覆盖「执行 → 干预 → 反馈」闭环，但规则散落在各页零碎提示里，新用户不理解达标、印章、阶段、静修时段等概念。本轮补上引导层：新增「修行手册」全屏页，并在新用户注册后自动打开一次；同时把用户已改的品牌名「一炷香 → 篆香」在项目内统一。

## 2. 入口与首次引导

- 入口：「我的」页新增「修行手册」按钮，与「账号管理」「工具」并排一行。
- 形式：点击进入全屏页（复用计时器全屏页模式：隐藏 nav/brandbar，顶部返回按钮）。
- 首次引导：**注册成功后自动打开一次**；登录不自动弹（老用户从「我的」进入）。
- 已读标记：localStorage `yizhuxiang-manual-read` = 用户名；点「我明白了」或返回时写入。

## 3. 手册内容（9 节）

每节 = 小标题（朱砂色中文数字 + 名称）+ 一句核心 + 一句展开（hint 风格）：

1. **燃香**：开始一场专注，就是点燃一炷香。写下目标、设定时长，香燃尽即到点；中途分心可点「分心」，完成时做一次简短自评。
2. **达标与印章**：每天达标，才盖一枚实印。当天完成 ≥15 分钟、完成率 ≥60%、平均完成度 ≥60 即达标，今日「香」字印为实印。
3. **回神仪式**：分心不可怕，回来就好。破功后回来选一个原因；受训期有反馈建议，训练阶段越高打扰越少。
4. **外缘**：把你容易陷进去的事物写下来。在「设置 → 外缘」添加应用名，专注时遇到即记一次分心。
5. **静修时段**：给每天留一段固定的专注时辰。设定起止时间，到点打开页面会提醒你开始（即原「深度时段」）。
6. **裸专注日**：每周一天，完全靠自己。当天不检测、不提醒，只留计时与手动「分心」。
7. **训练阶段**：干预随你的表现逐步退场。受训期 → 过渡期 → 预备毕业，检测、补问、仪式逐步减少。
8. **连续达标**：休息不算断，用了没达标才算断。没使用产品的日子直接跳过。
9. **毕业**：近 4 周达标率 ≥60%，且过半场次靠自己，即可毕业。卷轴展开，脱离产品也能专注。

底部主按钮「我明白了」。
