# 待办事项设计（2026-08-06，v2 打卡项目）

## 1. 目标
待办列表支持「打卡项目」：用户每天要做的事，今天完成后不消失（移入「今日打卡」分组），第二天自动恢复；并显示连续打卡天数。普通待办完成即消失。去掉手动上下移排序。

## 2. 交互
- 待办项操作：开始专心 / 完成打卡（仅打卡项目未完成时）/ 打卡（设为/取消打卡项目）/ 改 / 删；无上移下移
- 打卡项目：显示「每日」标记 + 「已打卡 N 天」（连续天数，断一天归零）
- 打卡项目今天完成后 → 列表底部「今日打卡」分组，显示「✓ 今日已完成」，保留不消失
- 第二天读取时服务端自动重置为未完成，回到主列表（连续天数保留）
- 完成方式：直接点「完成打卡」即可，也可从待办开专注、正常完成后自动完成打卡
- 排序：按创建时间（新增在前），不支持手动排序

## 3. 数据与接口
- todo 表新增：done_date（完成日期）、is_daily（打卡开关）、streak（连续天数）、last_checkin（最近打卡日）
- 老库自动 ALTER 补列
- PATCH /api/todos/{id}：text / is_daily / done（done=true 时写 done_date；打卡项按昨天是否打卡累计或重置 streak）
- GET /api/todos：读取时把「昨天完成」的打卡项重置为今天未完成
- 会话 PATCH complete 联动：同步写 done_date 与 streak（与手动打卡一致）
- 删除 POST /{id}/move 接口（排序功能移除）

## 4. 不做（YAGNI）
补打卡、提醒通知、打卡与专注统计/印章联动、多打卡目标、日历视图。
