# 一炷香：香燃计时器设计文档

- 日期：2026-08-05
- 状态：已获用户口头批准（2026-08-05）
- 依据：用户需求「加一个类似番茄钟的计时器，做成一炷香的动画形式」+ grill-me/brainstorming 确认结论

## 1. 背景与目标

**一句话定位**：把专注页的数字倒计时替换为「一炷香燃烧」动画——香燃尽即到点，让"专注如修行"从口号变成视觉。产品名就叫一炷香，计时器就该是一炷香。

## 2. 需求确认记录（brainstorming 结论）

| 问题 | 结论 |
|---|---|
| 与现有计时器关系 | A：替换现有专注计时（会话记录/破功/自评全部照旧） |
| 时间显示 | C：香为主 + 显示「已燃 X 分钟」（不显示剩余） |
| 视觉方向 | A：水墨单香——细香竖立、朱砂香头、灰烬、一缕轻烟 |
| 到点行为 | B：香尽收束态——整根变灰烬、烟散开、显示「一炷香已尽」，用户自己点「完成专注」（可随时提前完成） |
| 实现方案 | 方案一：CSS + JS 轻动画（无 Canvas） |

## 3. 功能设计

### 3.1 香的结构（视觉）
- 一根竖立的水墨香：高约 320px（视口 40% 左右）、宽 8~10px
- 香头：朱砂红小圆点（燃烧前沿），带微光
- 灰烬：灰白色段，从香顶向下累积（燃烧后的部分）
- 未燃香身：墨色段，从灰烬底部到香底
- 轻烟：香头处一缕烟上升 + 扩散 + 淡出（纯 CSS 装饰动画）
- 香下方一行小字「已燃 X 分钟」（X 为实际已专注分钟数）

### 3.2 燃烧映射
- 一根香的完整燃烧 = 会话计划时长（planned_minutes）
- 进度 p = elapsed / (planned * 60)，clamp [0, 1]
- p 驱动：灰烬高度 = p×100%、未燃香身高度 = (1-p)×100%、香头位置 = p×100%
- 到点（p≥1）：香头熄灭消失、整根变灰烬、轻烟散尽，出现「一炷香已尽」提示
- 会话提前完成（用户点完成）：香保持当前进度，正常进自评

### 3.3 交互不变
- 破功 / 完成 / 放弃按钮位置与行为不变
- 计时精度沿用时间戳差值（不依赖 setInterval）
- 手机端竖屏同样适配（香高度按视口比例）

## 4. 技术实现

### 4.1 HTML（home-running 计时区替换）
- 原 `#timer` 数字替换为：
  - `.incense`（容器，flex column）：`.incense-ash`（灰烬）+ `.incense-tip`（香头，绝对定位）+ `.incense-burn`（未燃香身）
  - `.incense-smoke`（轻烟，纯装饰）
  - `.incense-time`（「已燃 X 分钟」）
  - `#incense-done`（「一炷香已尽」，默认 hidden）

### 4.2 JS（tick 改造）
- `tick()` 不再更新 `#timer`，改为：
  - 计算进度 p → 更新 ash/burn 高度、tip 位置（style）
  - 更新「已燃 X 分钟」（elapsed 分钟，向下取整）
  - p≥1 → 显示香尽状态（tip 隐藏、smoke 淡出、incense-done 显示）
- 进度为 0 时香完整；新会话重置

### 4.3 CSS
- `.incense`：宽 9px、高 min(180px, 26vh)、相对定位、居中，下留 30px 放香炉
- `.incense-ash`：香头卷曲灰帽（固定约 9px，随燃点下移，--incense-ash-*）
- `.incense-burn`：未燃香身，高度由 JS 设为 (100-进度)%，从底部锚定、顶部逐寸消失；三层背景（圆柱光影 + 纵向纤维纹 + 斜向螺旋纹，--incense-wood-*）
- `.incense-tip`：8px 橙红燃点（--ember-*）+ 三层光晕 + 暖色 halo（::after）+ 呼吸动画
- `.incense-smoke`：10 个烟球 span（左右交替飘散）+ 静态烟柱 ::before（三层椭圆烟团，S 形左右摆动），烟色分昼夜（--smoke-*）；`.incense-fall`：4 粒灰烬周期性从香头掉落（下落+旋转+淡出）
- `.incense-burner`：古铜圆腹三足香炉（按用户提供实拍图参考重制），`top:100%` 贴于香底（宽 124px 高 78px，圆腹扁身、宽>高）；厚椭圆口沿（--burner-rim 高光）+ 深色炉膛 + 灰堆（香插其中）、圆腹+腹部横向高光+腰线（--burner-*）、环形双耳（环耳）、三足（中间+两侧 box-shadow）、落地投影；古铜颗粒质感用隐藏 SVG feTurbulence 滤镜（#bronze）；纯 CSS+内联滤镜无图片
- `.incense-time`：muted 小字，居中
- `prefers-reduced-motion`：动画关闭但保留静态烟柱（避免烟雾完全不可见），香与香炉仍按进度静态显示
- 昼/夜双模式：香身为物理固有色（两套一致），烟雾颜色随主题（深色用白烟/浅色用灰烟），香炉古铜昼夜微调（--burner-*）

## 5. 测试计划
- jsdom：
  - 专注页香元素存在（incense/ash/burn/tip/smoke/time）
  - 无会话时香不显示；会话开始后显示
  - 已燃分钟随 elapsed 更新（用注入的 started_at 断言「已燃 N 分钟」）
  - 进度属性：构造进度后 ash/burn 高度、tip top 正确
  - 香尽状态：elapsed ≥ planned 时 incense-done 显示、tip 隐藏
  - 旧 `#timer` 断言全部迁移
- e2e：
  - 专注页香结构可见（视觉断言）
  - 已燃分钟显示
  - 截图人工确认（昼/夜、香、烟、香尽态）

## 6. 不做（YAGNI）
- 香灰掉落粒子、火焰动画、燃烧音效
- Canvas 粒子系统
- 独立「点香」快速计时工具
- 破功时香的特殊状态
