# 一炷香：前端视觉重塑设计文档

- 日期：2026-08-04
- 状态：待用户审阅
- 关联文档：`docs/superpowers/specs/2026-08-03-focus-training-design.md`（产品设计，逻辑不变）

## 1. 背景与目标

- 现状：原品牌 FocusDojo，深色 + 薄荷绿 + 大圆角工具风。功能完整，但无个性、无记忆点，与"训练而非依赖、毕业"的产品理念没有视觉关联。
- 目标：
  1. 品牌更名为 **一炷香**（Yizhuxiang），标语"点一炷香，专注一炷香"。
  2. 视觉重塑为 **书道道场** 气质：墨色/宣纸/朱红印章，让界面气质本身成为产品理念的一部分。
  3. 增加 **昼夜双模式**（跟随系统 + 手动切换 + 记忆）。
- 范围：纯前端（`static/`）+ 名称/文档替换。后端 API、数据模型、监控逻辑、产品规则一律不动。

## 2. 品牌

- 中文名：一炷香；拼音/包名：yizhuxiang。
- 标语：点一炷香，专注一炷香。
- Logo：方印（朱砂红底 + 白色"香"字，楷书/衬线骨感），尺寸约 28px，放在品牌行左侧。
- 印章语义（签名元素）：
  - 完成一场专注（自评提交后）→ 当天盖一枚印。
  - 当天达标 → 实心朱印；未达标 → 空心印框。
  - 今日区域 = 一枚大印（盖"香"字，当天达标才实印）+ 本周 7 枚小印集印条（7 枚，实印=今天是几号就实印哪枚、下方标"今"，其余为空心印框；小印只标今天，不承载达标语义）。
  - 印章只由既有达标判定 + 今天日期驱动（服务端 `/api/stats/daily`、`/api/stats/weekly` 已有数据），不新增后端规则。

## 3. 设计方向：书道道场

- 一句话：整个界面像一间安静的练功房——墨色与宣纸、朱红印章、衬线大字计时器；"专注"是每天盖一印，"毕业"是拿到结业卷轴。
- 与理念的对应：
  - 觉察 → 今日数字与分心次数，像"观"；
  - 训练 → 启动仪式与计时器，像"练功"；
  - 习惯 → 集印条与连续达标，像"日常功课"；
  - 毕业 → 统计页结业卷轴进度。
- 气质执行原则：朱砂红是唯一强调色（印章 + 开始/完成/提交这类关键动作），其余元素安静克制；圆角整体收小（面板 14→8px、按钮 10→6px、印章 4px），更方正硬朗，避免"可爱工具 App"感。

## 4. 色彩系统（昼夜两套 CSS 变量）

### 夜（墨）

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | `#14141c` | 页面底色（墨青黑） |
| `--panel` | `#1d1d28` | 面板 |
| `--panel2` | `#26263a` | 输入框/次级面板 |
| `--text` | `#ece7dd` | 正文（宣纸暖白） |
| `--muted` | `#8f8a80` | 次要文字 |
| `--accent` | `#c8443c` | 朱砂红：印章/主操作 |
| `--gold` | `#c9a05c` | 铜金：达标点缀（极少用） |
| `--line` | `rgba(255,255,255,.08)` | 描边 |
| `--overlay-bg` | `rgba(12,12,18,.82)` | 弹窗遮罩 |

### 昼（宣纸）

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | `#f1ece2` | 页面底色（宣纸米白） |
| `--panel` | `#faf7f0` | 面板 |
| `--panel2` | `#e7e0d2` | 输入框/次级面板 |
| `--text` | `#221f1a` | 正文（墨黑） |
| `--muted` | `#7c766b` | 次要文字 |
| `--accent` | `#b84238` | 朱砂红（浅底上略沉） |
| `--gold` | `#a8843c` | 铜金 |
| `--line` | `rgba(0,0,0,.10)` | 描边 |
| `--overlay-bg` | `rgba(30,26,20,.50)` | 弹窗遮罩 |

- 默认 `:root` = 夜；`@media (prefers-color-scheme: light)` 对无 `data-theme` 的页面自动切昼；`:root[data-theme="light"/"dark"]` 为手动覆盖，优先级最高。无 JS 也能跟随系统。
- 焦点可见性：`:focus-visible` 用朱砂色 outline（昼夜同）。

## 5. 字体

- 显示字体（标题、计时器、数字、印章字、品牌名）：
  `"Noto Serif SC", "Source Han Serif SC", "Songti SC", "STSong", "SimSun", serif`
- 正文字体（正文、按钮、输入、提示）：
  `system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`
- 计时器：显示字体 + `font-variant-numeric: tabular-nums`，字号 64px。
- 不加任何网络字体（离线/PWA 可靠，国内网络可用）。

## 6. 布局与组件

```
┌ 印(香) 一炷香                昼/夜 ┐   ← 品牌行（新增）
┌ 专注 │ 统计 │ 设置 ┐
┌──────── 今日 ────────┐
│  [今日大印]  专注 0 分 · 场次 0    │
│  分心 0 次 · 连续达标 0 天          │
│  本周：一 二 三 四 五 六 日          │
│  ○ ● ○ ○ ○ ○ ○  （集印条，7 枚）  │
│  ┌ 这次要完成什么？ ────────┐       │
│  │ 任务输入 · 时长滑杆            │
│  │       [ 开始专注 ](朱砂印钮)   │
│  └──────────────────────┘        │
│  [回弹任务入口（未达标日出现）]     │
└─────────────────────────────┘
计时中：衬线大字 00:00 + 任务名 + 破功了/放弃/完成 + 离线徽标
统计页：周柱状图(朱砂/铜金) + 达标卡片 + 结业卷轴 + 洞察 + 应用建议/刷新
设置页：黑名单 / 目标时长 / 深度时段 / 提醒开关（仅换肤）
弹窗：启动仪式 / 质量自评 / 归因 / 补问 → 统一"纸笺"卡片 + 印式标题
```

- **品牌行**（新增，`#brandbar`）：左 = 方印 logo + "一炷香"（衬线）；右 = 日夜切换按钮（文本"昼/夜"，显示当前模式的另一面）。
- **专注页**：
  - 今日区块：大印 + 4 个数据（专注分钟/完成场次/分心次数/连续达标天）+ 本周集印条。数据卡片保持数字大字 + 小标签结构，仅换色与圆角。
  - 启动仪式卡片：宣纸质感面板，标题"这次要完成什么？"，输入 + 时长滑杆 + 朱砂"开始专注"。
  - 计时面板：衬线大字计时器、任务名、"破功了"（ghost）、"放弃"（ghost、墨灰描边）、"完成"（朱砂）。放弃不再用亮红，避免与主操作抢注意力。
  - 回弹入口、离线徽标、提示文案保留原位置与语义。
- **统计页**：
  - 周柱状图：保留柱状结构，填充色用朱砂/铜金（达标日朱砂，其余 panel2）。
  - 达标卡片：保持数字 + 标签。
  - **结业卷轴**（新增展示）：面板内一行"连续达标 X 天 · 距毕业约 N 周"（N = max(0, ceil((28 − streak)/7))，距 28 天目标还差的周数，向上取整），下方细进度条 = `min(连续达标天/28, 1)`，附一句"连续 4 周达标，即可毕业脱离产品"。毕业判定逻辑属 MVP 之外，此处仅按 28 天（4 周下限）做进度展示，不构成产品规则变更。
- **设置页**：结构、控件、文案不变，仅换肤；不加"跟随系统"开关（YAGNI，右上角按钮已覆盖）。
- **弹窗**：`.overlay-box` 加顶部小印装饰（朱砂方块 + 标题），面板/遮罩走变量；四个弹窗行为与显隐逻辑完全不动（`hidden` 属性机制保留）。
- **toast**：位置与行为不变，换肤。
- 无障碍：移动端响应式保留（单列自适应）；`:focus-visible` 可见；`prefers-reduced-motion` 时禁用主题过渡动画。

## 7. 日夜切换实现

- CSS 结构：
  - `:root { }` 定义夜变量；
  - `@media (prefers-color-scheme: light) { :root:not([data-theme]) { } }` 定义昼变量（跟随系统）；
  - `:root[data-theme="light"] { }` / `:root[data-theme="dark"] { }` 显式覆盖。
- JS（`app.js`）：
  - 启动时读 `localStorage["yizhuxiang-theme"]`，有则写入 `document.documentElement.dataset.theme`，无则不动（跟随系统）。
  - 按钮点击在 light/dark 间切换：写 `data-theme` + `localStorage`；按钮文案同步。
  - 主题切换时 body 加过渡（`transition: background-color .15s, color .15s`），`prefers-reduced-motion: reduce` 时关闭。
- 注意：`[hidden] { display:none !important; }` 规则必须原样保留，弹窗显隐继续走 hidden 属性，不引入新的 display 控制 class。

## 11. 成功标准

1. 新界面一眼有"书道道场"个性，非模板工具感。
2. 昼夜两套完整、切换即时、选择被记住；无 JS 时也能跟随系统。
3. 原有功能全回归：会话流程、弹窗显隐、离线补交、SW 更新均不回退。
4. 改名全覆盖：`rg -i "focusdojo"` 除旧文档外 0 命中（`codex_chat/`、`node_modules/` 除外）。
5. 用户打开 `http://127.0.0.1:8000/?v=6` 即见新界面，之后正常访问无需再带版本号。
