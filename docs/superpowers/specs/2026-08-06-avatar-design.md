# 头像上传设计（2026-08-06）

## 1. 目标
点击「我的」页圆形头像可本地上传头像；上传后可拖动图片、缩放调整，圆形取景框覆盖的区域即最终头像。

## 2. 交互
- 点击圆形头像（默认「香」章）→ 唤起本地文件选择（image/*）
- 裁剪弹层：圆形取景框 + 拖动图片 + 缩放滑块（1~3x）；「确定/取消」
- 确定 → 生成 256×256 圆形头像（透明圆角）→ 上传 → 头像即时更新；无头像时显示原「香」章
- 校验：图片类型、≤5MB

## 3. 实现
- 后端：POST /api/auth/me/avatar（multipart，按用户 id 存 data/avatars/{uid}.png）；/avatars 静态挂载取图
- 前端：原生 <input type="file"> + canvas 自绘圆形裁剪（无第三方库）；拖动用 Pointer Events
- 头像 URL 带时间戳防缓存

## 4. 不做（YAGNI）
头像显示到其他页面、多尺寸压缩、外部裁剪库、云端图床。
