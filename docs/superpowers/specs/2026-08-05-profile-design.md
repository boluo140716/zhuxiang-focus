# 一炷香：个人中心设计文档

- 日期：2026-08-05
- 状态：已获用户口头批准（2026-08-05）
- 依据：用户需求「设置个人中心页面，登出入口放那里」+ grill-me 确认结论

## 1. 背景与目标

**一句话定位**：把「登出」从品牌栏收进一个完整的「我的」页面，集中展示账号身份、累计履历与账号管理（改昵称/改密码），让账号体系有归属感，也为后续内容（月度体检、毕业证书）留位置。

## 2. 需求确认记录（grill-me 结论）

| 问题 | 结论 |
|---|---|
| 个人中心定位 | C：账号信息 + 我的数据 + 改昵称/改密码 |
| 入口位置 | A：第四个导航标签「我的」（专注/统计/设置/我的） |
| 「我的数据」内容 | 账号履历：累计专注时长/完成场次/分心次数/达标天数/靠自己完成率 + 身份信息（与统计页"近期"数据错开） |
| 改密码后登录态 | A：强制重新登录（清令牌回登录页） |

## 3. 功能设计

### 3.1 导航
- 顶部导航 3 → 4 个标签：专注 / 统计 / 设置 / **我的**
- 登出按钮从品牌栏**移除**，移入「我的」页（品牌栏只留主题切换）

### 3.2 「我的」页结构（三块）
1. **身份卡**：头像印章（昵称首字 + 朱砂底，圆形）+ 昵称 + 用户名 + 注册日期
2. **累计履历**（卡片组）：累计专注时长（小时/分钟）、累计完成场次、累计分心次数、累计达标天数、靠自己完成率（有数据时显示百分比，无数据显示 —）
3. **账号管理**：
   - 改昵称：输入框 + 保存（登录态保持，身份卡即时刷新）
   - 改密码：旧密码 + 新密码 + 确认密码；成功 → toast + 清令牌 → 跳登录页
   - 登出：清令牌 → 登录页

### 3.3 边界
- 头像不做上传（YAGNI），默认昵称首字印章
- 用户名不可改（登录凭证，保持稳定）

## 4. 技术设计

### 4.1 API
- `PATCH /api/auth/me`：body {nickname} → 更新昵称 → 返回 {id, username, nickname, created_at}
- `POST /api/auth/password`：body {old_password, new_password} → 校验旧密码（错则 400「旧密码不正确」）→ 更新密码哈希 → 返回 {ok: true}
- `GET /api/auth/summary`：当前用户累计数据：
  - total_focus_minutes（完成场次 actual_minutes 之和）
  - total_completed（完成场次）
  - total_distractions（分心记录数）
  - qualified_days（达标日数，复用 training_service）
  - self_rate（靠自己比例，复用 reliance_stats 思路，无数据显示 null）
- `GET /api/auth/me` 响应补 `created_at`（前端注册日期展示）

### 4.2 前端
- `#nav` 增加第 4 个按钮（data-view="me"）；switchView 支持 "me"
- 新增 `#view-me`：身份卡 / 履历卡片 / 账号管理表单
- 履历数据在 switchView("me") 时拉 `GET /api/auth/summary` + `GET /api/auth/me`
- 改昵称成功后刷新身份卡；改密码成功 → clearToken + showAuth + toast
- 登出按钮移入 view-me（原 `#btn-logout` 从品牌栏删除）
- 样式沿用现有卡片/按钮体系，昼夜双模式自适应

### 4.3 安全
- 改密码必须校验旧密码（防止他人改）
- 改密码后旧令牌由前端主动清除（方案 A：强制重新登录）
- 密码哈希沿用 pbkdf2（app/services/auth.py）

## 5. 测试计划
- pytest：
  - PATCH /api/auth/me 改昵称成功/空昵称 400
  - POST /api/auth/password 成功/旧密码错 400/新密码过短 400
  - GET /api/auth/summary 聚合正确（种数据断言各字段）
  - me 返回 created_at
- jsdom：个人中心渲染（身份卡/履历/账号管理）、改昵称流程、改密码跳登录、登出入口存在且品牌栏无登出
- e2e：登录 → 进「我的」→ 改昵称 → 改密码 → 跳登录 → 新密码登录成功；登出按钮位置断言

## 7. 不做（YAGNI）
- 头像上传/更换、用户名修改、邮箱绑定、第三方登录
- 双令牌/刷新令牌体系
- 「我的」页展示他人数据或社交功能
