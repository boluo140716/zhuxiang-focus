# 计时器小工具设计（2026-08-05，v2 全屏化）

## 1. 目标
「我的」页工具分类是工具入口列表（计时器为第一个，后续可加更多工具）；点击工具卡片进入该工具的全屏页。计时器：无需命名、进入即自动开始倒计时。

## 2. 交互
- 「我的」页：账号管理旁「工具」折叠按钮（默认收起）→ 工具卡片列表（名称+说明+箭头）
- 卡片外只设置时长：预设 5/10/15/25/30 分钟 chips + 自定义输入（1~120），时长标签联动
- 点击「计时器」卡片 → 全屏计时页：隐藏导航与品牌栏，仅剩左上角「← 返回」
- 进入即自动开始；大号 mm:ss 居中，正下方三个按钮：暂停(暂停/继续切换) / 重置 / 停止
- 到点：00:00 + 「时间到」+ 提示音（可关）+ toast；不自动返回
- 点击「返回」：计时立即结束，回到「我的」页

## 3. 实现
- 纯前端（无后端）；时间戳计时（endAt），500ms 轮询
- 状态 timerState 暴露 window.__fd.timer 供测试；音频环境不可用静默降级
- prefers-reduced-motion：到点闪烁动画关闭

## 4. 不做（YAGNI）
正计时、历史记录、系统通知、返回后后台继续计时（返回即结束）、其他工具占位卡片。
